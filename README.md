# حصة الشبكة اليومية — تطبيق Android أصلي

هذا مشروع منفصل عن قالب Expo السابق، ويستخدم Kotlin وJetpack Compose. المرحلة الحالية تقتصر على الهيكل والواجهة العربية RTL.

## حالة المرحلة الأولى

- واجهة لوحة رئيسية عربية مع حقل تجريبي لتعديل الحصة وشريط يوضح موضع العداد.
- لا يوجد عدّ حقيقي لحركة البيانات أو حفظ دائم للحد في هذه المرحلة.
- لا توجد إشعارات أو خدمة VPN أو إيقاف اتصال في هذه المرحلة.
- لا توجد وحدة Huawei ولا أي اتصال بالراوتر.
- توضح الواجهة أن الحصة ستطبق على الهاتف المثبت عليه التطبيق فقط.

## البناء

المشروع معدّ لـ Android Gradle Plugin 8.7.3 وKotlin 2.0.21 وAndroid SDK 35. يلزم تثبيت Android Studio/SDK وGradle محليًا لإجراء بناء فعلي. لم تُنزّل أو تُثبّت أدوات بناء خلال هذه المرحلة، ولم يُنفّذ بناء لأن Gradle وAndroid SDK غير متاحين في بيئة العمل الحالية.

افتح هذا المجلد في Android Studio بعد توفر Android SDK، ثم نفّذ Gradle Sync وبناء التطبيق. لا تضع بيانات دخول الراوتر في التطبيق أو في المحادثة.
